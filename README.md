# Jun Jin · 金君

Academic homepage at the School of Mathematical Sciences, Yangzhou University.

Website: https://junjin17116.github.io/

## Structure

Home · Papers · Papers by topics · Grants · Group · Teaching

Static HTML and CSS; no framework or package installation required. GitHub Pages publishes from the main branch, repository root.

## Update

Edit `site-data.json`, run `python3 build.py`, and commit the regenerated HTML pages. To use a photograph, add `assets/photo.jpg` and change the `portrait` field.

Publication lists, grants, students and formal course listings may be extended in the data file. Current details are also linked to the official university profile.

Official profile: https://teacher.yzu.edu.cn/JJ1234567/zh_CN/index/496567/list/index.htm

The layout follows the academic site structure of https://xingcaigithub.github.io/index.html using original HTML/CSS and responsive styling.
